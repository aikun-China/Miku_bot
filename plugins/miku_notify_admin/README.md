# 通知管理员插件

当用户在群聊或私聊中发送「通知管理员」「对管理员说」等关键词时，Bot 会自动将消息转发给所有管理员。

## 功能特性

- 支持多种触发关键词
- 区分群聊和私聊格式
- 自动排除管理员自己的消息
- 支持转达内容的智能提取

## 触发关键词

- 通知管理员
- 告诉管理员
- 对管理员说
- 跟管理员说
- 转告管理员
- 有事找管理员
- 跟他说
- 帮我跟管理员
- 帮我告诉管理员
- 麻烦告诉管理员
- 请告诉管理员
- 能不能告诉管理员

## 消息格式

### 群聊

```
群聊名字:XXXX群
昵称(123456789)：通知内容
```

### 私聊

```
昵称(123456789)：通知内容
```

## 使用示例

| 用户发送 | 管理员收到 |
|---------|----------|
| `通知管理员 你好` | 群聊名字:XXX群\n昵称(123)：你好 |
| `对管理员说 建议增加天气功能` | 群聊名字:XXX群\n昵称(123)：建议增加天气功能 |
| `告诉管理员 bot很棒` | 昵称(123)：bot很棒 |

## 注意事项

- 管理员发送的通知不会被转发（避免循环）
- 消息会自动提取关键词后面的内容
- Bot 会回复用户「已将消息转达给管理员」
